# Memory Game

## Описание проекта

Классическая игра на развитие памяти (Find a pair). Цель игры — открыть все пары карточек за минимальное количество ходов. Разметка приложения полностью генерируется динамически с помощью JavaScript.

## Стек технологий

- HTML5 (пустой body, только скрипт)
- CSS3 (Flexbox, Grid, 3D-анимация переворота карт)
- Vanilla JavaScript (ES6+, DOM API)

## Функционал

- Автоматический старт игры и перемешивание карт (Алгоритм Фишера-Йейтса)
- Подсчет ходов и найденных пар
- Модальное окно победы
- Таблица лидеров (Топ-10 лучших результатов сохраняются в LocalStorage)
- Полная адаптивность под мобильные устройства

## Как запустить локально

1. Склонируйте репозиторий:
   ```bash
   git clone <ссылка_на_твой_репозиторий>
   ```
2. Перейдите в ветку проекта:
   ```bash
   git checkout memory-game
   ```
3. Откройте файл `index.html` в браузере (или запустите через VS Code расширение Live Server).
