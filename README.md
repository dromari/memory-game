# Memory Game

## 📝 Описание проекта

**Memory Game** — это интерактивная игра на поиск парных карточек («Найди пару»), развивающая визуальную память. Игрок поочередно открывает карточки, стремясь за минимальное число ходов очистить игровое поле.

**Ключевая особенность реализации:** Полное соответствие жестким требованиям архитектуры RS School. Исходный файл `index.html` содержит абсолютно пустой тег `<body>` (кроме подключения скрипта). Вся структура интерфейса, игровое поле, анимации и модальные окна генерируются исключительно динамически через JavaScript с использованием безопасных методов DOM API (`document.createElement`).

---

## 🚀 Функционал и особенности приложения

- **Динамический рендеринг:** Генерация 100% разметки "на лету" без использования `innerHTML` или сторонних фреймворков.
- **Умное перемешивание:** Карточки тасуются по алгоритму Фишера — Йейтса при каждой загрузке и перезапуске.
- **Контроль состояния:** Реализована строгая блокировка поля (`isBoardLocked`) во время демонстрации несовпавших карт (таймаут настроен на оптимальные 1000 мс).
- **Архитектурный ООП-подход:** Модальные окна победы и таблицы лидеров построены на базе единого переиспользуемого класса `Modal`.
- **Локальное хранилище (LocalStorage):** Сохранение ТОП-10 лучших результатов с автоматической сортировкой по количеству ходов и дате (формат `ДД.ММ.ГГГГ`).
- **Адаптивный дизайн:** Интерфейс плавно подстраивается под любые экраны (десктоп, планшеты, смартфоны).

## 💻 Локальный запуск

1. Склонируйте репозиторий на свой компьютер:
   ```bash
   git clone https://github.com
   ```
2. Перейдите в каталог проекта:
   ```bash
   cd memory-game
   ```
3. Переключитесь на рабочую ветку:
   ```bash
   git checkout memory-game
   ```
4. Запустите проект в браузере. Рекомендуется использовать расширение **Live Server** для VS Code, либо просто откройте файл `index.html` напрямую в любом современном браузере.
