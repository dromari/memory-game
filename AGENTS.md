# Memory Game — руководство для AI-агентов

## Обзор проекта

Memory Game — это классическая браузерная игра на развитие памяти ("Найди пару"). Игрок открывает карточки и пытается найти все совпадающие пары за минимальное количество ходов.

Проект представляет собой статичное фронтенд-приложение без серверной части, сборщиков и пакетных менеджеров. Все файлы лежат в корне репозитория.

## Текущее состояние кода

- `index.html` — минимальная HTML-обертка с пустым `<body>`, подключает `style.css` и `script.js`.
- `README.md` — документация проекта на русском языке, описывающая планируемый функционал.
- `script.js` — пустой файл (реализация игры отсутствует).
- `style.css` — пустой файл (стили отсутствуют).

Фактически репозиторий содержит только HTML-скелет и описание; игровая логика, визуальные стили и DOM-разметка пока не реализованы.

## Стек технологий

- HTML5
- CSS3
- Vanilla JavaScript (ES6+, DOM API)

Сборщики, фреймворки, библиотеки, транспайлеры и системы управления зависимостями не используются.

## Структура проекта

```
memory-game/
```

## Запуск и разработка

### Локальный запуск

Откройте файл `index.html` в браузере двойным кликом, либо запустите через локальный сервер (например, Live Server в VS Code).

```bash
# Пример запуска через Python (если установлен)
python -m http.server 8000
```

После запуска откройте в браузере: `http://localhost:8000`

### Сборка

Сборка не требуется. Проект состоит из статических файлов.

## Тестирование

В проекте отсутствуют тесты и тестовые фреймворки.

Для проверки работоспособности используйте ручное тестирование в браузере:

1. Откройте `index.html`.
2. Убедитесь, что карточки отображаются и перемешиваются.
3. Проверьте, что открытие двух карточек засчитывается как один ход.
4. Проверьте, что найденные пары остаются открытыми.
5. Проверьте появление модального окна при победе.
6. Проверьте сохранение результатов в LocalStorage.
7. Проверьте адаптивность на мобильных устройствах через DevTools.

## Соглашения по стилю кода

- JavaScript: ES6+, без сторонних библиотек.
- Разметка генерируется динамически в JavaScript; `index.html` остается с пустым `<body>`.
- CSS: используйте Flexbox/Grid для раскладки и 3D-трансформации для анимации переворота карточек.
- Именование переменных и функций — на английском языке, в стиле camelCase.
- Комментарии и документация — на русском языке, в соответствии с README.
- Состояние игры (количество ходов, найденные пары, таблица лидеров) хранится в LocalStorage.

## Безопасность

- Проект не использует сервер, базу данных или внешние API.
- Не сохраняйте в LocalStorage конфиденциальные данные пользователя.
- Данные таблицы лидеров легко подделаны на стороне клиента — рассматривайте их только как локальную функцию.
- При добавлении внешних зависимостей проверяйте их источник и актуальность версий.

## Планируемый функционал (из README)

- Автоматический старт игры и перемешивание карт (алгоритм Фишера-Йейтса).
- Подсчет количества ходов и найденных пар.
- Модальное окно победы.
- Таблица лидеров (топ-10 результатов в LocalStorage).
- Адаптивная верстка для мобильных устройств.
