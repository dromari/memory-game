# Сессия: реализация Memory Game

## Текущее состояние проекта

- `index.html` — содержит только `<script src="script.js"></script>` в `<body>`, соответствует требованиям ТЗ.
- `style.css` — реализована тёмная тема, Grid-сетка 4×4, 3D-анимация переворота карточек, стили модальных окон и адаптивность.
- `script.js` — полностью реализована игровая логика на чистом Vanilla JS.
- `README.md` — базовая документация на русском языке (уже была).

## Выполненные задачи

1. Изучены требования RS School по ссылке: https://github.com/rolling-scopes-school/tasks/tree/master/tasks/memory-game
2. Создан `style.css`:
   - Тёмная нейтральная тема с CSS-переменными.
   - Центрированная Grid-сетка 4×4 для игрового поля.
   - 3D-переворот карточек через `preserve-3d`, `backface-visibility`, `rotateY(180deg)`.
   - Модальные окна с оверлеем, анимацией и блокировкой прокрутки (`body.modal-open`).
   - Hover-эффекты для кнопок и карточек.
   - Адаптивная вёрстка для мобильных устройств.
3. Создан `script.js`:
   - Вся разметка генерируется через `document.createElement` и DOM API.
   - Отсутствуют `innerHTML`, `outerHTML`, `insertAdjacentHTML`, `document.write`, `DOMParser`, `Range.createContextualFragment`.
   - Отсутствуют `alert`, `confirm`, `prompt`.
   - 16 карточек (8 пар эмодзи), перемешивание алгоритмом Фишера-Йейтса.
   - Счётчики ходов и пар.
   - Логика открытия/закрытия карточек с задержкой 1000 мс для несовпавших пар.
   - Блокировка поля во время задержки.
   - Кнопка «Новая игра» сбрасывает игру, отменяет таймер и закрывает модалки.
   - Универсальный компонент `Modal` для окон победы и таблицы лидеров.
   - Сохранение топ-10 результатов в `localStorage`, сортировка по ходам и дате.
   - Модалки закрываются по кнопке, оверлею и клавише Escape.
4. Проведена проверка синтаксиса JS (`node --check script.js` — успешно).

## Архитектурные решения

- **Модульная структура**: код разбит на секции — утилиты, состояние, игровая логика, таблица лидеров, модальные окна, построение UI.
- **Чистый DOM**: используется единый хелпер `createElement` и `clearElement` для работы с DOM без строкового HTML.
- **Переиспользуемый компонент**: класс `Modal` используется для обоих модальных окон.
- **Состояние**: централизованный объект `state` + массив `activeModals` для управления открытыми окнами.
